# PRD v3：代理单角色结算平台 Demo

> 当前目录：`billing-platform/`  
> 快照保留：`billing-platform-v2/` 为上一版「代理 / 网吧主双角色 + 关联审批」Demo。  
> 当前结论：取消网吧主角色、取消网吧主分成，所有业务操作由代理执行。

## 1. 当前主链路

```mermaid
flowchart LR
  A[现有 QQ 登录/资质认证] --> B[代理向迪越/区域经理获取网吧 ID]
  B --> C[代理录入网吧资料]
  C --> D[平台审核资料]
  D -->|通过| E[代理线下铺设霸服]
  D -->|驳回| C
  E --> F[已活跃终端/日活/月活/流水回传展示]
```

说明：

- `网吧 ID` 不是平台在录入后分配的，而是代理提前向迪越侧或相应区域经理获取。
- 平台审核只审核代理提交的网吧资料是否有效，不作为“分配网吧 ID”的业务节点。
- `MCxxxx` 仅作为 Demo 内部系统记录 ID，不作为主链路对外讲解重点。

## 2. 登录与资质

- 首页 `/` 保留 QQ `扫码登录`、`密码登录`。
- 密码登录 Demo：点击 `登录（模拟资质已认证）` 后直接进入代理控制台。
- 首页保留 `完善资质` Tab，用于演示“已登录但资质未完善”的录入流程。
- 小入口保留：注册账号、意见反馈、联系客服。

## 3. 录入网吧字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 网吧 ID | 是 | 代理从迪越侧/区域经理获取；不知道时联系相应区域经理 |
| 网吧名称 | 是 | 代理人工录入 |
| 所在地区 | 是 | 省/市级联 |
| 详细地址 | 是 | 需具体到门牌号或楼层 |
| 终端规模数 | 是 | 代理人工编辑维护，不等于已活跃终端 |
| 现场联系人 | 是 | 可后续编辑 |
| 联系电话 | 是 | 可后续编辑 |

## 4. 终端数据口径

| 指标 | 口径 |
| --- | --- |
| 终端规模 | 代理人工维护的门店终端规模数，录入时填写，后续可编辑 |
| 已活跃终端 | 原 `terminalCount`，由铺设上线/数据回传模拟产生 |
| 日活终端 | 当日活跃终端数，网吧管理表格需单独展示 |
| 月活终端 | 当月活跃终端数 |
| 月活率/日活率 | 月活/日活 ÷ 终端规模 |
| 实际流水 | 只展示已产生/已结算实际流水，不展示“本月预估”口径 |

## 5. 页面调整

### 5.1 概览首页 `/agent/dashboard`

- 右上角只保留 `录入网吧`，去除 `代理信息` 按钮。
- 顶部摘要展示：录入网吧数、已上线数、终端规模、已活跃终端。
- “最近动态”模块已移除。
- 待审核提示改为：审核通过后可安排铺设；网吧 ID 由代理提前获取。

### 5.2 网吧管理 `/agent/my-cafes`

- 表格展示：网吧 ID、系统 ID、网吧名称、终端规模、已活跃终端、日活终端、月活/月活率、流水、状态、联系人。
- 操作列新增 `编辑`。
- 编辑弹窗支持修改：网吧名称、详细地址、终端规模数、现场联系人、联系电话。
- 流水记录弹窗只展示实际/已结算流水记录，不展示本月预估口径。
- 终端规模统计卡展示 `terminalScaleCount` 求和。

### 5.3 代理信息 `/agent/profile`

- 只展示代理基础资料、实名信息、联系方式。
- 移除“代理名下网吧”模块。

### 5.4 平台管理端 `/admin/audit`

- 平台管理端是代理数据看板的上级视角，代理看板是平台管理端按单个代理过滤后的子集。
- 平台管理端分为 `总览`、`网吧明细`、`审核记录` 三个 Tab。
- 总览展示：代理数、网吧数、终端规模、已活跃终端、实际流水、待审核单数，并提供代理数据看板。
- 网吧明细展示：每一家网吧、归属代理、终端规模、已活跃终端、日活、月活、实际流水、状态、联系人。
- 审核记录展示：待审核列表、已审核记录、通过/驳回操作。
- 平台审核不讲“分配网吧 ID”。
- 审核通过文案为“资料审核完成，代理可安排铺设上线”。

## 7. 研发注意事项

1. 后端建模时，`externalCafeId` 应按业务唯一键处理。
2. `terminalScaleCount` 是代理可编辑字段；`terminalCount / dailyActiveTerminal / monthlyActiveTerminal` 是回传数据字段。
3. 不要把“网吧 ID”设计成平台审核后分配；平台只做资料审核。
4. 联系人、电话、地址允许代理在网吧管理页编辑。
